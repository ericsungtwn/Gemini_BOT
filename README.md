# ClawWeb Assistant v2.0

ClawWeb is a personal AI assistant inspired by OpenClaw, built with React, Express, and Google Gemini API.

## 🚀 Features

- **Gemini 3.1 Pro Integration**: Advanced reasoning and multi-modal capabilities.
- **Persistent Memory**: SQLite-backed conversation history.
- **Telegram Integration**: Send messages, reminders, and voice processing directly to Telegram.
- **Web Browsing**: Real-time web content extraction and screenshots.
- **GitHub Sync**: One-click synchronization of project source code to GitHub.
- **Stock Alerts**: Set price alerts for global and Taiwan stocks.
- **Technical Dashboard**: Professional, scannable, and informative UI.

## 🛠️ Tech Stack

- **Frontend**: React 19, Tailwind CSS 4, Motion, Lucide Icons.
- **Backend**: Express.js, Better-SQLite3, WebSocket.
- **AI**: Google Gemini API (@google/genai).
- **Tools**: Octokit (GitHub), Puppeteer (Web Browsing), Node-Telegram-Bot-API.

## ⚙️ Configuration

To run this project, you need to set the following environment variables in your Secrets:

| Variable | Description |
| --- | --- |
| `GEMINI_API_KEY` | Your Google Gemini API Key |
| `TELEGRAM_BOT_TOKEN` | Your Telegram Bot Token |
| `TELEGRAM_CHAT_ID` | Your Telegram Chat ID(s) |
| `GITHUB_TOKEN` | GitHub Personal Access Token |
| `GITHUB_REPO` | GitHub Repository (e.g., `user/repo`) |

## 📦 Installation

1. Clone the repository.
2. Install dependencies: `npm install`.
3. Start the development server: `npm run dev`.
